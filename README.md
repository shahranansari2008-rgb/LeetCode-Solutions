## ⚙️ Automation

Every push to `main` triggers a workflow that scans folders matching `####-problem-name`, rebuilds the solutions table, recalculates topic counts, and commits the README only when its content changes. You can also run it manually from **Actions → Update LeetCode README → Run workflow**.

**Folder naming convention:** `0009-palindrome-number/`, `0263-ugly-number/`, etc. The workflow does not fetch solutions from LeetCode; LeetHub (or your own upload) remains responsible for adding the folders.
